# besnovatyj/yii2-cms-snippets

Модуль **сниппетов** — заготовленных кусков HTML/текста, которые контент-менеджер вставляет
в контент WYSIWYG-редактора из тулбара (поиск + категории + превью).

Полный замысел, раскладка по репозиториям и порядок реализации — в [PLAN.md](PLAN.md).

## Что делает этот пакет

- Домен: категории (`snippet_groups`) и сниппеты (`snippet_snippets`), CRUD-админка
  (тело сниппета правится фасадом `Besnovatyj\Editor\EditorWidget`).
- Реализует контракт `Besnovatyj\Contracts\snippet\SnippetProvider` (источник из БД).
- Компонент-агрегатор `snippetCatalog` собирает дерево из **всех** модулей-провайдеров
  (`instanceof SnippetProvider`) — как модуль меню собирает `MenuTargetProvider`.
- JSON-эндпоинт дерева для фронтового пикера: `GET /Snippets/backend/api/tree`.

## Границы

- Пикер-UI и вставка — вне этого пакета: движко-независимое npm-ядро
  `@besnovatyj/snippets-core` + тонкая связка в пакете движка (`yii2-cms-jodit`).
- Сниппет ≠ шорткод: сниппет вставляется в контент как HTML (edit-time), шорткод —
  плейсхолдер, резолвимый на рендере (render-time). Они компонуются: тело сниппета может
  содержать шорткоды.
